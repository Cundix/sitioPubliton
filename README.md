# Publitón — Hackeando el mensaje

Sitio del proyecto académico de Fiscina, Fuentes, Diaz y Tana.

Información del evento, programa conceptual, pases individuales y de equipo, formulario con validación, revisión de datos, confirmación y descarga de un pase SVG de muestra. Incluye enlaces a los prototipos de Comida y Premios en Figma.

La reserva es una demostración: no crea inscripciones reales, no envía correos y no conserva datos al recargar la página. Los lectores QR/NFC de los tótems también están simulados.

Sitio estático sin dependencias. Publicación mediante GitHub Pages desde la raíz de `main`. Para probarlo localmente, servir esta carpeta con un servidor HTTP estático.

Tipografías Anton y Barlow, distribuidas con sus licencias SIL Open Font License en `assets/`.
